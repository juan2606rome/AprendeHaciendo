Nueva tarea

Se crearán dos archivos en tu carpeta data/: un .md con el enunciado y un archivo de código vacío.

Solo .js se ejecuta dentro de la página. .md trae editor con vista previa. .png (o .jpg/.gif/.webp/.svg) se sube como foto. Los demás se editan como texto plano o se abren con “Abrir en VS Code”.

¿En qué carpeta de tu computador está ese archivo?

Aunque ya seleccionaste la carpeta arriba, por seguridad ningún navegador (ni Chrome, ni Brave, ni ninguno) le permite a una página saber la ruta real de una carpeta en tu disco — solo te deja leer y escribir dentro de ella. Por eso este es el único dato que te voy a pedir escrito, y solo una vez: se guarda en este navegador y no te lo vuelvo a preguntar.

Tu navegador tiene esto apagado por defecto

Para poder leer y escribir carpetas de tu computador, esta página usa la File System Access API del navegador. Chrome y Edge la traen encendida, pero Brave la trae apagada por defecto (por privacidad) y hay que encenderla a mano — una sola vez.

  1. Abre una pestaña nueva y ve a brave://flags/#file-system-access-api
  2. Busca “File System Access API” y cambia el selector de Default a Enabled.
  3. Brave te va a pedir reiniciar (botón Relaunch) — dale clic.
  4. Vuelve a esta página y elige Probar tú mismo otra vez.
Los enlaces brave:// no se pueden abrir con un clic por seguridad del navegador, por eso hay que copiar y pegar la dirección tú mismo en una pestaña nueva.
Abre esta misma página en Chrome o Edge — ahí la File System Access API viene activada por defecto y no hace falta ningún paso extra.
